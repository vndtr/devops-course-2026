## Что удобно в VS Code для работы с Git

1. **Визуальный diff.** При изменении файла достаточно кликнуть по нему в панели
   Source Control — открывается встроенный diff-редактор с подсветкой добавленных
   и удалённых строк. Не нужно помнить флаги `git diff` и разбираться в консольном
   выводе.

2. **Staging и коммит в один клик.** Рядом с каждым файлом есть значок `+`
   (Stage Changes), а сверху — поле для сообщения коммита и галочка Commit.
   Полный цикл `git add` + `git commit` выполняется мышкой без набора команд.

3. **Удобное разрешение конфликтов слияния.** При merge-конфликте VS Code
   показывает встроенный редактор с кнопками «Accept Current», «Accept Incoming»,
   «Accept Both» — выбрать нужный вариант можно визуально, а не вручную править
   маркеры `<<<<<<<` и `>>>>>>>`.

## Что удобнее в терминале

- **Интерактивный rebase (`git rebase -i`)** и сложные операции вроде
  `cherry-pick`, `reflog`, `bisect`. В UI VS Code они либо недоступны, либо
  реализованы ограниченно. Кроме того, на сервере (по SSH) доступен только
  терминал — поэтому важно уметь работать с Git именно в CLI.
