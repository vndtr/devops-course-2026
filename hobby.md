# Мой пет-проект

**Идея:** телеграм-бот для учёта личных расходов. Пользователь пишет боту
сумму и категорию («500 еда», «1200 транспорт»), бот сохраняет записи
в базу и по команде `/report` показывает статистику за месяц.

**Стек:** Python, aiogram, SQLite (на старте), Docker для запуска.

**Цель:** научиться писать асинхронных телеграм-ботов, работать с базой
данных и упаковывать приложение в Docker-контейнер.
